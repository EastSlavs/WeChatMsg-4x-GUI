# 修改声明

本项目基于 [chenanhan230-del/WeChatMsg-4x](https://github.com/chenanhan230-del/WeChatMsg-4x) 修改。

维护者：EastSlavs  
修改日期：2026-11-01

## 沿用的功能

- 微信 PC 4.x 数据目录识别
- 数据库密钥提取和解密
- 联系人、会话及消息读取
- 基础聊天记录导出

## 本项目的修改

- 完善 V2 图片解密，支持自动获取密钥并导出图片
- 增加 Tkinter 图形界面
- 增加当前登录账号选择和独立数据库管理
- 增加导出前数据库更新、校验和备份
- 增加联系人搜索和多选
- 增加界面及命令行日期筛选
- 增加导出内容选择
- 增加语音批量转换和 ZIP 打包
- 改进本地文件附件匹配
- 改进多会话导出索引，增加结果统计
- 增加运行日志、取消入口和联系人刷新
